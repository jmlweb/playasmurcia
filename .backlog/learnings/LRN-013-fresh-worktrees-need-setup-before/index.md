## Context
A fresh worktree has no `node_modules`, `local.db`, `.dev.vars` or `src/routeTree.gen.ts`. Build, test and check fail with "no such table" or missing route types. Hero photos are also absent.
## Insight
routeTree is generated by `pnpm build`/`pnpm dev`. Tests need a seeded `local.db`: copy it from the main checkout, or run `pnpm drizzle-kit push --force` then `pnpm tsx scripts/migrate-to-database.ts`. Production credentials are not needed and the permission system denies copying them.
## Application
In a worktree: `pnpm install --frozen-lockfile`, copy `local.db`, `pnpm build`, then test/check. For screenshots use `turso dev --db-file local.db --port 8181` with a local `.dev.vars`, and copy `public/pictures` or set `VITE_PICTURES_BASE_URL` for photo checks.
