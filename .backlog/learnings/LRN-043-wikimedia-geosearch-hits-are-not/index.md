## Context
2 km geosearch and text search returned many unrelated or wrong-place files.
## Insight
A title containing the beach name can still be a different place. "Playa de Las Amoladeras" is in Almería. Commons categories show where a file really is.
## Application
Check categories and coordinates before approving, and view each candidate.
