## Context
A fresh worktree makes pnpm check fail on routeTree.gen type errors and pnpm build fail with no tables.
## Insight
routeTree.gen.ts is only generated by running vite. The sitemap step in pnpm build needs a populated DB.
## Application
Run pnpm exec vite build first to generate the route tree. Copy or create local.db and .dev.vars for build, DB tests and screenshots.
