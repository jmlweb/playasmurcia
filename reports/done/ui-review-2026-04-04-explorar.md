# UI Review — Explorer (`/explorar`)

**Evidence:** `/tmp/ui-review-explorar.png`, `/tmp/ui-review-explorar-mobile.png`.

## Design Directive: Explorer

### Critical (must fix)

- None.

### Important (should fix)

- **Same as cross-cutting**: Results grid suffers from small tag typography on cards and visible empty placeholders when many beaches lack photos.

### Refinement (nice to have)

- **Mobile filter entry**: Filter + sort + count + page indicator stack is dense; ensure tap targets for “Filtrar” and sort dropdown meet 44px minimum and that focus rings are visible on real devices.
- **Long pagination**: Many pages when unfiltered is expected; optional future pattern “Load more” is product scope, not a defect.

### What works well

- **Hero search** + sidebar accordions (desktop) deliver a credible “directory” experience.
- **Breadcrumb** “Inicio / Explorar playas” matches other inner routes.

**Severity summary:** Critical: 0, Important: 1, Refinement: 2
