# Service: Social Media Feeds

## Description

Display user-generated content from Instagram/TikTok on beach pages.

## Details

- **Tools**: Curator.io, Juicer, or Elfsight
- **Integration**: Filter by hashtag or location

## Prerequisites

- Add `instagramHashtag` field to beaches.json (e.g., "#PlayaDeBolnuevo")

## Implementation Notes

- Embed widget filtered by beach hashtag
- Keeps content fresh without manual updates
- Consider moderation options
